# Web 图库管理

## 进入页面

本插件 v0.3.0 要求 **AstrBot >=4.29.0 且 <5.0.0**。已核对 4.29.0 发布标签提供 `views/`、`AstrBotPluginView` 和所需的 `astrbot.api.web` 接口；4.28.2 虽有后端 Web API，但没有本页面使用的 `AstrBotPluginView` 名称。独立浏览器验证使用的是 4.29.3 源码。升级 AstrBot 并重载本插件后，从 **WebUI → 插件 → 表情包图库详情 → 图库管理** 打开页面。

管理页随插件发布，无需 Node.js、构建前端、额外端口或管理令牌。所有请求通过 AstrBot 提供的 bridge 和已认证的 Dashboard 插件扩展接口处理。界面跟随 Dashboard 的明暗主题。

不满足声明范围时，AstrBot 会按版本约束阻止加载。代码中缺少 `astrbot.api.web` 时保留聊天功能的逻辑仅作为防御性降级，不代表旧版本受支持；无法直接双击 HTML 文件使用管理功能。

## 管理图库

- 点击「新建」，填写图库名称。名称与聊天命令采用相同校验规则。
- 左侧输入名称或别名筛选图库；选择「全部图片」可跨图库查找。
- 选择图库后点击「管理图库」可重命名、添加或移除别名。
- 「删除整个图库」会删除图库、所有别名、图片记录及原文件，操作前会显示确认框。不能撤销；重要数据请先停止插件并备份整个运行数据目录。

重命名保留图库 ID、图片 ID 和已有别名。正在导入的队列使用图库 ID，其他会话重命名图库不会改变导入目标；删除后重建同名图库也不会接收旧队列的图片。

## 管理图片

每页最多 20 张图片，可输入完整图片 ID 查找。列表缩略图展示首帧，动图右上角显示 GIF 标志；点击图片可打开原图窗口，直接显示上传的原始文件，浏览器支持的动图会播放。可切换「原始尺寸」与「适应窗口」，大图在原始尺寸模式下可滚动查看。

「编辑图片」可保存所属图库，或单独选择文件并点击「替换原图」。移动和替换保留图片 ID；目标图库存在重复图片时会拒绝操作，保留原数据。替换原图不能撤销。

单张删除和勾选后的批量删除都会要求确认，批量删除会报告部分失败。仅删除图片会保留空图库及别名，已删除 ID 不会重新使用。

## 批量导入

1. 选择或创建一个目标图库，点击「导入图片」。
2. 多选图片，或选择本地文件夹。文件夹中的文件逐张校验，非图片会报告失败，不会执行或解压文件。
3. 点击「开始导入」。界面按顺序上传，列出成功 ID、重复 ID 和失败原因。
4. 「停止后续导入」会等待当前文件处理结束后停止，已完成的导入保留。关闭或刷新页面不会回滚已导入的图片。

每次选择会替换待导入队列。一个文件失败不会中断后续导入。使用浏览器支持的文件夹选择能力，不支持 ZIP 压缩包导入。

单张大小复用 `max_download_mb`（默认 20 MB）。与聊天上传共用图片解码限制和图库内 pHash 去重：1600 万像素、500 帧、总解码像素 1 亿。上传保留原始字节。Dashboard 或反向代理若设置了更小的请求体限制，也可能拒绝上传。

## 验证范围

自动化测试覆盖存储事务回滚、替换与删除恢复、ID 保留、去重、分页、请求校验、大小限制及 bridge 页面交互。API 可通过本地 AstrBot 官方 `astrbot.api.web` 进行独立适配验证；此验证不等同于完整 AstrBot 启动、实际登录鉴权和 QQ 协议端联调。
