# 插件命令

[] 为必填参数
<> 为可选参数
|  连接多个可以使用的参数

## 帮助命令

帮助    /图库帮助   发送本帮助图片

## 图库命令

创建新图库    /创建[图库名]
             /创建 [图库名]

重命名图库    /图库重命名 [旧图库名] [新图库名]

删除图库    /图库删除 [图库名|图库别名]    删除整个图库及其全部图片和别名

查看所有图库    /图库列表
               /看所有

图库别名操作    /图库别名 [图库名]    显示该图库的所有别名
               /图库别名 [图库名] [添加] [图库别名1] <图库别名2> ... <图库别名n>    添加图库别名
               /图库别名 [图库名] [删除] [图库别名1] <图库别名2> ... <图库别名n>    删除图库别名(管理员)

## 图片命令

上传图片    /上传[图库名|图库别名]

删除图片    /删除[图片ID1] <图片ID2> ... <图片IDn>   删除指定 ID 的图片(管理员)
           /删除 [图片ID1] <图片ID2> ... <图片IDn>   删除指定 ID 的图片(管理员)

查看图片    /看所有[图库名|图库别名]    查看图库中的所有图片
           /看[图库名|图库别名]<x[数字]|*[数字]>    随机查看指定图库中的图片
           /看 [图库名|图库别名] <x[数字]|*[数字]|[数字]>    随机查看指定图库中的图片
           /看[图片ID1] <图片ID2> ... <图片IDn>    查看指定 ID 的图片
           /看 [图片ID1] <图片ID2> ... <图片IDn>    查看指定 ID 的图片

## 图片处理

翻转图片    /翻转 <水平|垂直>    默认水平翻转
           /flip <horizontal|vertical>    默认水平翻转

镜像图片    /镜像 <上|左|下|右>    默认以左半边为基础
           /mirror <top|left|bottom|right>    默认以左半边为基础

加速动画    /加速 [倍数]x    倍数须大于 0
           /speed [倍数]x    倍数须大于 0

倒转动画    /倒转    倒转动画播放顺序
           /reverse    倒转动画播放顺序

# 提示

## 上传图片

可用的图片上传方法为：

- 在发送上传指令的同时发送需要上传的图片
- 在发送上传指令的同时引用包含了需要上传的图片的消息(普通图片、动画表情、转发消息)
- 在发送上传指令后根据机器人的提示在指定时间内发送包含图片的消息(图片、动画表情、转发消息)，仅读取首条消息
