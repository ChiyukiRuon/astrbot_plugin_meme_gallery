# 表情包图库

面向 AstrBot 的 aiocqhttp（OneBot v11）插件，支持图库上传、随机取图、按 ID 取图、缩略图预览，以及静态图和动态图处理。

## 安装

本插件 v0.4.1 支持 **AstrBot >=4.29.0 且 <5.0.0**，版本范围通过 `metadata.yaml` 的 `astrbot_version` 声明。Web 管理页面依赖该版本起提供的 `AstrBotPluginView` bridge；已使用 4.29.3 源码中的官方 API 和 bridge 完成独立浏览器验证，尚未完成完整 AstrBot 登录联调。

将本插件放到 AstrBot 的 `data/plugins/` 下，在 WebUI 中重启AstrBot以重载插件。

帮助图和缩略图需要中文字体。可在插件配置 `font_dir` 中填写字体文件夹路径，在 `font_order` 中按优先级排列字体文件名；缺字时自动使用后面的字体。Docker 部署时填写容器内路径。具体示例见[字体配置说明](docs/fonts.md)。

插件数据保存在 AstrBot 的 `data/plugin_data/astrbot_plugin_meme_gallery`，包含 SQLite 索引和原始图片。备份时请在停止插件后复制整个数据目录。

## Web 管理界面

在支持[插件可视化视图](https://docs.astrbot.app/dev/star/guides/plugin-pages.html)的 AstrBot 中，重载插件后打开 **WebUI → 插件 → 表情包图库详情 → 图库管理**。

支持新建、搜索、重命名、删除图库与管理别名；按 ID 查找图片、分页预览、点击查看原图与播放动图、移动图片到其他图库、替换原图、单张或批量删除；支持多选文件和选择文件夹批量导入，显示进度及每张图片的成功、重复或失败结果。

界面复用 AstrBot 登录和插件视图 bridge，无需额外端口、令牌或前端构建。详细操作、限制和升级说明见 [Web 图库管理](docs/web-management.md)。

## 聊天命令

命令遵循 AstrBot 当前会话的唤醒前缀设置。也遵循 AstrBot 的 @ 机器人、引用机器人消息和私聊唤醒规则。私聊是否需要前缀取决于 AstrBot 配置。下表省略前缀。

| 命令                                                        | 说明                                     |
| ----------------------------------------------------------- | ---------------------------------------- |
| `图库帮助`                                                | 以图片形式发送插件用法                   |
| `创建猫猫` / `创建 猫猫`                                | 创建图库，上传前必须先创建               |
| `图库重命名 猫猫 猫咪`                                    | 修改图库名，保留图片、ID 和已有别名      |
| `图库删除 猫猫`                                          | 删除整个图库及其全部图片、原文件和别名   |
| `图库别名 猫猫`                                           | 显示该图库全部别名                       |
| `图库别名 猫猫 添加 小猫 猫咪`                                 | 添加别名                                 |
| `图库别名 猫猫 删除 小猫 猫咪`                                 | 删除别名                                 |
| `图库列表` / `看所有`                                   | 显示全部图库及各图库图片数量，以第一张图片为封面   |
| `看猫猫`                                                  | 从“猫猫”图库随机取一张图片             |
| `看猫猫x3` / `看猫猫*3` / `看 猫猫 3`                 | 随机取多张图片                           |
| `看12 34` / `看 12 34`                                  | 按全局图片 ID 查看                       |
| `看所有猫猫`                                              | 显示图库名称、全部别名和带 ID 的缩略图，动图标注 GIF   |
| `删除 12 34`                                              | 按 ID 删除图片记录及原文件               |
| `上传猫猫` / `添加猫猫`                                 | 上传图片到已创建的图库，不存在时返回提示 |
| `翻转 [水平/垂直]` / `flip [horizontal/vertical]`       | 默认水平翻转                             |
| `镜像 [上/左/下/右]` / `mirror [top/left/bottom/right]` | 以指定半边为基础镜像，默认左边           |
| `加速 2x` / `speed 0.5x`                                | 调整动画播放速度，小于 1 为慢放          |
| `倒转` / `reverse`                                      | 倒转动画帧顺序                           |

表中方括号表示可选参数，不需要输入括号。

上传支持命令附图、引用图片消息、引用合并转发、先发命令后发图片。合并转发只读取第一层节点中的图片，不递归读取嵌套转发或节点内引用。上传结果会回复原始上传指令，并列出新图片 ID 和失败原因。

只有 `创建图库名` 命令可以创建新图库。空图库会在图库列表中显示占位封面；重复创建会提示已存在。升级时会自动将旧版本已有图片所属的图库迁移为图库记录，保留原图片和 ID。

图库名和别名共用全局唯一名称空间，别名遵循图库名的命名规则。可通过别名查看、上传和管理别名，例如 `看小猫x3`、`看所有小猫`、`上传小猫`。缩略图顶部始终显示正式图库名及全部别名，长内容自动换行；空图库也显示名称、别名和占位图。添加、删除均支持用空格分隔多个别名，无需引号，例如 `图库别名 猫猫 添加 小猫 猫咪 喵喵`。重复项自动合并，逐项处理并反馈结果；某项名称冲突或不存在时不影响其他项。单个名称本身含空格时请用双引号包围，例如 `图库别名 "猫 猫" 添加 "小 猫"`。

重命名支持通过正式名称或别名指定图库，新名称不能与任何图库名或别名重复（包括本图库已有别名）。旧名称释放，不自动保留为别名；已有别名继续可用。含空格的名称请用双引号包围，例如 `图库重命名 "猫 猫" "猫 咪"`。已在等待后续图片的上传任务会继续上传到重命名后的原图库。

删除命令会合并重复 ID，逐项处理并报告不存在的 ID 或删除失败的原因。删除封面后，下一张图片成为封面；删除全部图片后，图库和别名仍保留。已删除图片可重新上传并获得新的 ID。删除操作默认开放，可通过插件管理员权限配置限制。

`图库删除 猫猫` 会删除整个图库、全部图片及别名，支持通过别名指定图库；含空格的名称请用双引号包围。此操作受“删除图库”权限控制，与按 ID 删除图片的权限独立。

图片处理支持附图、引用普通图片消息、后续发图，一次只处理一张图片。动态图会逐帧处理；加速和倒转需要动态图。

后续发图等待默认 120 秒，按平台、会话、发送者隔离；同一用户在同一会话发送新的有效命令会替换原来的等待任务。超时后直接丢弃等待任务，不主动发送超时消息。

成功触发上传或图片处理命令后，后续发送图片无需再次添加前缀或 @ 机器人。未按 AstrBot 唤醒规则触发的文字不会作为新命令执行。

## 配置与行为

- `admin_ids`：插件管理员 QQ 号列表，每项一个 QQ 号，默认空。名单为空时所有用户都允许执行命令。
- `admin_gallery_permissions`：图库权限多选，支持创建图库、重命名图库、删除图库、添加图库别名、删除图库别名，默认不选。
- `admin_image_permissions`：图片权限多选，支持上传图片、删除图片，默认不选。
- `multi_image_mode`：`direct` 在一条消息中发送多张图；`forward` 每张图一个转发节点。
- `forward_threshold`：默认 5，超过此数量强制合并转发。
- `send_as_meme`：默认开启，通过 OneBot `sub_type=1` 发送；是否显示为表情包取决于协议端支持。图库预览始终按普通图片发送。
- `wait_timeout`：后续发图等待秒数，默认 120。
- `max_download_mb`：单张图片最大下载及 Web 上传体积，默认 20 MB。
- `font_dir`：字体文件夹路径，读取其中的 `.ttf`、`.otf`、`.ttc`、`.otc` 文件，不递归读取子文件夹。留空自动寻找系统字体，也兼容旧配置中的 `font_path`。
- `font_order`：按优先级排列的字体文件名列表，第一项为主要字体；未列出的字体按文件名排序追加。目录内文件名需与列表中的名称一致。

只有管理员名单非空且对应权限被选中时，该聊天命令才仅限名单内的用户执行；群主、群管理员和 AstrBot 管理员不会自动加入此名单。未选中的命令仍可使用，查询别名、查看图片、帮助与图片处理不受这些权限限制。上传权限涵盖“上传”和“添加”、附图、引用和后续发图；后续图片到达时会重新检查权限。保存配置并重载插件后生效。Web 管理页继续使用 AstrBot 登录权限，不使用聊天 QQ 号名单。

一次查看最多 20 张；随机取图不重复抽样，图库图片不足时发送全部现有图片。图库名不能是纯数字，也不能以 `x数字`、`*数字` 或空格加数字结尾，避免与 ID 和数量语法冲突。图库在本插件实例中共享。

去重只在同一图库内进行，跨图库允许收录同一图片。静态图计算 pHash；动态图逐帧计算 pHash，只有帧数、帧顺序以及各帧哈希都一致才判为已存在。播放时长不参与去重。pHash 衡量视觉相似性，并非字节相等，可能把视觉接近的图片判为重复。

上传保留原文件；静态处理结果为 PNG，动态处理结果为 GIF，因此动画输出存在调色板量化，时长以 10 毫秒为最小单位。奇数宽高镜像保留中间行或列。

为限制处理内存，单张图片最多 1600 万像素、动画最多 500 帧且总解码像素不超过 1 亿。`图库列表`、`看所有` 和 `看所有图库名` 的预览超过单张 1600 万像素时自动拆成多张，保留全部条目，每张均显示完整标题和别名。多张预览按 `multi_image_mode` 和 `forward_threshold` 发送，仍使用普通图片格式；单张预览保持直发。

聊天中的图库预览会缓存最近使用的缩略图，重复查看时减少原图解码；文件变化后自动重新生成。缓存最多 512 项，仅占用内存（像素数据最多约 53 MiB），重启后重新建立。动画预览仍显示首帧，GIF 标记只探测第二帧，不再扫描总帧数。

首次生成预览时，JPEG 使用解码降采样，不透明图片优先缩小后再转换颜色模式，以减少大图处理开销。保留 EXIF 方向校正和透明图片的边缘处理；缩略图采样细节可能略有差异，原文件不变。

## 开发验证

```sh
python -m unittest discover -s tests -v
python -m compileall -q main.py gallery
```

测试覆盖图片处理、存储去重、命令解析、OneBot 消息结构和模拟 AstrBot 事件流程。模拟测试不代表真实 QQ 协议端联调已通过。

插件接口依据 [AstrBot 插件开发文档](https://docs.astrbot.app/dev/star/plugin-new.html) 和本地 AstrBot 源码实现。

帮助图片按[帮助文案](docs/help.md)的标题、分组和文本生成，命令按功能、命令、说明三列对齐。文案中的“(管理员)”仅为示意；图片仅在管理员名单非空且对应权限启用时，在该命令说明后显示此标记。

帮助图使用当前会话 AstrBot 配置中的首个命令前缀；读取失败时使用 `/`，并在参数说明下显示“命令前缀请按实际情况使用，/仅做示意”。
